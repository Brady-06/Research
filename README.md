# 剪枝与蒸馏初步尝试

基于 YOLO11 在 COCO 数据集上的剪枝 / 蒸馏工作记录，按数据规模分三个阶段。目前剪枝已跑通、已有 baseline，等待后续推进。

## 剪枝

### 实验路线

| 阶段 | 数据 + 模型 | 工作内容 |
| --- | --- | --- |
| 1 | coco8 + YOLO11n | 流程验证、环境配置（实验 01） |
| 2 | coco128 + YOLO11n | 正式小规模剪枝：先用论文方法（贪心法）在 ultralytics YOLO11 上自动剪枝，再借助 AI 分析多种剪枝方法（实验 02–06） |
| 3 | coco2017 + YOLO11s | 尝试云服务器，耗时长、剪枝效果一般，暂未深入（实验 07–10） |

每个阶段都从 YOLO11 官方预训练权重出发：coco8 / coco128 微调得到 best.pt；coco2017 直接采用官方预训练 yolo11s.pt（实验 07，未再训练）作为剪枝基准。

### 主要结论

- 数据量小、经验不足，剪枝效果一般：GMACs 降低很少，Precision、mAP50、mAP50-95 损失偏高。
- 共性问题：无论低 / 中 / 高敏感层，最终都只能剪掉低敏感层中很少的一部分，剪幅上限受限，方法仍待探究。

## 蒸馏

- 计划：以 coco128 的 YOLO best 版本为学生模型，用 DINOv2 作为教师模型做蒸馏。
