# 实验06：敏感度分档剪枝 A–E 对比

结论：本轮 A 最好，但五组都未达到预先设定的精度要求。综合计算量和精度，继续使用实验05的贪心模型；本轮 A 模型仅保留作试验对照。

原模型 mAP50-95 为 0.6232。A 降至 0.5470（损失7.62个百分点），计算量减少4.07%；旧贪心模型复测为0.5962（损失2.70个百分点），计算量减少4.55%。A 参数压缩更多（4.17%，旧贪心1.69%），但精度代价明显更大。

选型规则在开跑前固定：相对未剪枝对照，mAP50-95损失不超过2个百分点时，选计算量减少最多的一组。五组均不满足，因此保留精度最高的A，并明确其不达标。旧贪心也未达到这个更严格的2点要求，只是在现有剪枝结果中更适合继续研究。

B–E微调确实恢复了部分精度，但仍明显低于基线；A微调没有提高mAP，因此保留的是剪后原始检查点。最强E减少11.00%计算量、13.19%参数，微调后mAP仅0.3214，本轮没有找到兼顾明显压缩与小精度损失的拐点。

## 过程与设置

1. 起点：实验02的YOLO11n best.pt，所有组独立重新加载。COCO128分成102张训练、26张验证；未剪枝对照也额外微调10轮。
2. 分档：复用实验03的L1屏蔽敏感度。mAP50-95下降≤0.005为低，(0.005,0.020]为中，>0.020为高；候选根层38个（低9、中8、高21），均≥64通道，排除首层、注意力、检测头和已知不兼容根层。
3. 选通道：用全部102张训练图片、13个batch统计每通道mean(|权重×损失梯度|)。FP32、无增强、不更新权重、固定BN；已验证统计前后模型张量一致。这里的梯度重要性是额外的选通道策略，A–E本身指剪枝比例分档。
4. 删除：按目标比例四舍五入为整数通道，不强制对齐8。依赖图同步删除相连通道，并跟踪原始通道编号，避免重复剪或错用评分。每组检查320/640前向、反向和保存后重载。首层、注意力、CSP分块宽度、检测最终输出受保护；依赖可调整检测头输入及关联深度卷积。
5. 微调：各组10轮，AdamW、lr0=0.0001、batch=8、640、seed=42、关闭强增强，固定BN统计及仿射参数。检查损失有限、BN未变、剪枝结构保留。各组在剪后原始模型与微调best中保留精度较高者。

目标比例针对根层，依赖联动可能改变其他层，所以不能把表中比例当成全网计算量降幅。A/B/C各接受9次根层删除；D接受12次、拒绝4次；E接受22次、拒绝12次。其余已被依赖满足的目标不重复剪；拒绝主要因CSP分块或注意力结构约束。

## 对后续的启发

本次数据提示：单层低敏感，不保证多个低敏感层一起剪仍低敏感；而且原分档基于L1屏蔽，本次改用梯度评分，分档只是代理，无法保证25%剪枝仍安全。结果不足以证明梯度方法普遍更差，也不能只看FLOPs就判断速度。下一轮应以旧贪心为参照，重新测实际结构删除的影响，再逐步提高压缩目标。

验证集只有26张，还参与分层、选best和选方案；官方预训练也可能见过这些COCO图片。这是方法筛选记录，需在更大、独立的数据划分上复核。
