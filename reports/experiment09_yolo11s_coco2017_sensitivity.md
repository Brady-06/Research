# 实验 09：YOLO11s / COCO2017 逐层敏感度分析

## 结果文件

- [原始 CSV](experiment09_yolo11s_coco2017_sensitivity.csv)：87 层测试记录，另有 1 行表头。
- 实验日期：2026-09-09。
- 云端来源：`/root/YOLO/reports/experiment09_yolo11s_coco2017_sensitivity.csv`。
- 基线权重：云端 `weights/baseline/yolo11s_coco2017_best.pt`。
- 数据配置：云端 `configs/coco2017.yaml`，验证集为 COCO val2017 的 5,000 张图片。

## 方法与基线

使用 `scripts/prune_sensitivity.py` 的逐层独立测试逻辑；云端运行时设置为 imgsz=640、batch=128、workers=8、device=0，屏蔽比例为 0.10。

每个候选层均重新加载同一基线，按卷积核权重的平均绝对值排序，将最低的约 10% 输出滤波器权重及对应偏置（若有）置零，然后验证。候选为输出通道数至少 16 的 Conv2d，共 87 层。

CSV 中的基线 mAP50 为 **0.6098954756**，mAP50-95 为 **0.4450059486**。

## 主要字段

| 字段 | 含义 |
|---|---|
| layer | 卷积层模块名 |
| in_channels / out_channels | 原始输入 / 输出通道数 |
| ratio / masked_filters | 请求的屏蔽比例 / 实际置零滤波器数量 |
| baseline_mAP50_95 | 本次分析重新评估得到的基线精度 |
| trial_mAP50_95 | 当前层置零后的精度 |
| mAP50_95_drop | 基线减去试验精度；越大代表本测试下越敏感 |

负的 drop 表示本次测得的精度略高于基线，不能仅凭微小变化断言模型有所改善。

## 使用边界

本实验只修改卷积权重，不删除通道，也不减少张量尺寸或计算量。若后面有 BatchNorm，卷积置零后的通道输出不一定为零，因此该结果是筛选候选层的启发式指标，不等同于实际删除通道的影响。

检测头最终输出具有类别和框回归语义，不应仅因为 drop 较小就直接删掉其输出通道。结构化剪枝需另外检查依赖关系、前向与反向传播、保存重载，并重新评估精度。该 CSV 不包含后续结构化剪枝或微调结果。
